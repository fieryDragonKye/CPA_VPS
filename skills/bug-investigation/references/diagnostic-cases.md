# CPA 案例：防止误归因

以下来自 CPA Personal 2026-10 的历史资料，仅提示调查方向，不证明新故障相同。

| 现象 | 已确认的区分 | 可复用的诊断方式 |
|---|---|---|
| 光场卡顿 | SVG 柔光与玻璃背景模糊不是同一成本 | 分层关闭、相同条件重复测量，核对实际 Paint/Raster |
| 导航不连续 | 新旧页淡化重影、加载骨架和长任务可同时存在 | 生命周期、DOM 层数、opacity、请求与时间线分别关联 |
| 工具栏下沉 | 隐形但参与正常流的按钮，以及上方动态提示是独立原因 | 对照相对卡片坐标、计算定位、CSS 优先级和 DOM 顺序 |
| 数字蓝色高亮 | 原生文本选区，窗口失焦可变灰，不等于 checkbox 状态异常 | document.getSelection、activeElement、Focus 与状态更新分别观察 |
| Select 中文裁切 | 内层 overflow 与继承行高组合，不是外部控件必须加高 | 字形 Range、内容盒、计算样式、原生缩放和同类控件对比 |
| 900 行日志不顺 | 减少位置扫描有局部收益，却不一定改善整体 P95 | DOM 规模、HitTest、Paint/Raster 与脚本分项；候选验证完整语义 |
| 接口报错 | OAuth 授权问题、工具 call_id 历史缺失、TLS 握手 EOF 不能混作一个原因 | 按请求链路、时间和接口关联，区分本地与上游，先脱敏 |

反例：候选 CSS 在注入时有效却被构建转换；截图 API 在原生缩放下裁错区域；浏览器权限导致模拟与真实请求表现不同。保留失败实验，验证最终产物、几何和权限，不挑最好结果覆盖真实状态。
