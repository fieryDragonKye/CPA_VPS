# 前端性能专项诊断

## 测量口径

确认实际框架和版本，再决定是否采 React Render/Commit 等数据。不预设一定是 React、某种状态库或动画库。

分别采首次初始化、重复导航、缓存命中/未命中、持续动画、Hover、滚动、定时刷新。记录刷新率、浏览器版本、可见性、数据量、缩放与设备像素比；性能录制与轻量测量分开，重复样本而非只取平均 FPS 或最大峰值。

- rAF P50/P95/P99 和超周期比例是调度代理，不是实际物理丢帧率；解释刷新周期与计时容差。
- >50ms 长任务记录关联时间线与调用栈。只有生产压缩栈无源映射时明确定位精度，不能给未记录的峰值编造函数。
- Style/Layout/Paint/Raster/Composite 的 inclusive、并发或嵌套耗时不能直接相加当 CPU/GPU 墙钟时间。
- 录屏帧率可能不足，合成 wheel 不能代替实体鼠标。输入步进、事件延迟和可见滚动不连续分别判断。

## 一次隔离一层

按证据选择暂停装饰动画、隐藏光场、关闭背景模糊、关闭 SVG 滤镜、保留静态内容或隔离加载态。保留功能与几何条件，检查 scrollHeight、视口和 DOM 规模一致。不要一次关掉所有效果后归因于某一种。

导航检查布局/光场节点生命周期、路由叠层、入场样式、请求/骨架及同步布局。滚动检查 wheel/scroll 回调、位置读取、DOM 数量、更新频率与绘制。将数据刷新与导航碰撞作为独立条件。

## 优化候选的前提

- memo、startTransition、Worker、Keep-Alive、预加载需要实际计算或生命周期证据，不能作为默认补丁。
- will-change、translateZ(0)、contain 有层数、内存、包含块与布局语义代价，不能全局添加。
- backdrop-filter、SVG 滤镜与纹理解码分别评估；浏览器 GPU 工作不等同于云服务器 CPU。
- 虚拟化只有 DOM 规模确实成为瓶颈时才研究，并保留搜索、筛选、锚点、复制、追尾与历史查询；静态裁掉行数只证明性能上界。

最终重测实际生产构建，不以 DevTools 注入成功证明构建成功，不以代理指标改善替代用户交互验收。
