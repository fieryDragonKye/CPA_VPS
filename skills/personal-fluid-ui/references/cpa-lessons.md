# CPA 视觉与交互案例：经验及局限

来源为用户本机 CPA Personal 2026-10-22 至 2026-10-25 的交付与诊断报告，以下是历史证据摘要，非对当前项目重新测量。原报告保留在原项目的 UI优化、UI诊断目录，本 Skill 不依赖这些绝对路径运行。

## 可复用的结论

- 第四轮：Edge 155、Intel UHD630、60Hz、约 8GB 环境中，运行时 SVG 柔光改为两张静态透明 WebP，叠加无滤镜动态细光带。三页持续动画最终 P95 约 16.8–17.0ms；原版本多次约 33–50ms。两张 1280×800 纹理约 301KB 压缩、RGBA8 解码理论约 7.81MiB，后者不是测得的显存。仅停用玻璃模糊曾未取得同等改善，不能一概删除 backdrop-filter。
- 主按钮使用局部反射与一次性扫光，普通数据卡不伪装成按钮；重点、普通、密集区采用不同材质。参考图更复杂的折射与体积光未完全实现，不能把测试通过写成逐像素还原。
- personal.6 取消一级导航新旧正文 360ms/220ms 交叉淡化，布局和光场节点保持稳定；表面稳定中位数显著改善，导航 P95 仍约 33.5ms，最大任务仍约 198ms。重影与长任务是独立问题。
- 列表缓存应按身份/连接作用域隔离、有限时效、变更失效、阻止旧 GET 回填；缓存命中避免清空有效内容。CPA 的四分钟只属于该项目，不是通用 TTL，不持久化 Token。
- 自动刷新标签的数字高亮来自原生选区，局部 user-select 修复即可；加载图标预留空间避免按钮宽度变化。不能禁用全站选区或 Focus。
- Flex/Grid 最小尺寸约束需用实际宽度定位；表格内部可滚动，不以全局 overflow-x:hidden 掩盖裁切。
- 局部恢复追尾按钮被全局双类选择器覆盖定位，造成看不见但仍占正常流高度。用组件范围的精确选择器修复，不用负 margin。某候选属性在生产构建中被处理掉，说明必须验证最终产物计算样式。
- 等级 Select 的 line-height:1 加内层 overflow:hidden 导致 17.6px 字形被 13px 盒子裁切；仅局部行高 1.4 解决，外部按钮高度不变。实际浏览器 125% 缩放不同于只改 DPR 或 CSS zoom。
- 日志动态提示位于筛选工具栏前方会推移工具栏；调整 JSX 结构、保留 alert/status 和事件比遮罩或固定高度更小。布局修复不改变日志滚动算法。

## 不应推广为默认实现

900 行位置扫描降至少数读取只改善局部脚本，未稳定改善总耗时/P95；120 行诊断窗口虽更快，却未保留完整搜索、选区、锚点和追尾语义，不是可发布虚拟列表。

30FPS 录屏不能证明 60Hz 掉帧；合成 wheel 不等同于物理滚轮；模拟接口验收不等同于真实账号/模型链路；CSS 注入结果不等同于生产构建结果。测试中不可控权限、缓存与截图缩放错误应保留说明，不挑选最好候选数据替代最终数据。
