# 私人 Premium Fluid Glass 视觉系统

用于明确采用私人审美的网页。它是设计方向，不是固定布局模板，也不是物理折射引擎。

## 背景与空间

- 深墨蓝承载主体，青蓝、冷白与少量蓝绿色构成柔光；亮部集中于少数视觉重点，正文背景保持稳定。
- 由远及近组织：深色基底 → 静态柔光 → 少量动态细光带 → 玻璃面板 → 清晰文字与控件 → 局部反射。
- 光线应有弧线、遮挡和明暗差，避免全屏均匀渐变、过饱和霓虹与散乱光团。需要沉浸感时先改善后景层次，再调整前景透明度。
- 示例起点为背景 #071321、文字 #EAF5FF、装饰强调 #62D8FF；必须按实际背景和组件状态检验，不能假设强调色天然符合文字对比度。

## 三档材质

| 层级 | 用途 | 材质策略 |
|---|---|---|
| 重点玻璃 | 顶部工具栏、主面板、少数重点卡片 | 可见透叠、局部角落反射、细内高光；避免大块亮光穿过正文 |
| 普通玻璃 | 导航、常规卡片、提供商磁贴 | 更稳的底色与克制边缘光，弱于重点面板 |
| 密集数据 | 表格、表单、日志、小字说明 | 近实底或高不透明度；清晰优先，不做持续扫光 |

边缘反射具有方向性：少数边角偏亮，其余边缘安静。用静态渐变与局部伪元素形成弧面暗示，避免整圈同亮描边。不同材质共享色彩角色，但不共享同一透明度和阴影强度。

## 排版与交互层级

- 展示区可用更强标题对比；后台工作区按任务密度安排字号和留白，不照搬概念图的巨大标题。
- 静态指标卡不添加虚假按钮语义、键盘焦点或强烈上浮；主要可交互卡片才承担明显反馈。
- Hover、选中、Focus、Active 必须可分辨；选中状态应比临时 Hover 更稳定明确。
- 不把参考图中的账号、模型、额度、数据或功能当成真实业务。示意内容必须标识，现有产品保留原数据来源。
